# CaptureRecall marketing launch

The first audience is Linux developers who save terminal errors, code snippets, and debugging references. The promise is a useful retrieval workflow: capture deliberately, find the screenshot by visible text, and copy or drag it back into work. This is positioning to validate with users, not a claim that local OCR is unique.

Working assumptions: free MIT desktop preview, useful trials before paid offers, CAD $0 spend. These replace unanswered preference questions and can be revised. Do not buy ads, priority listings, or subscriptions under this plan.

## What a useful trial means

A tester installs a compatible package, saves three captures, finds the correct one using a visible phrase, and copies or drags it into another application. Record success or the step that failed. After seven days, ask whether they returned to a capture they actually needed. This can be self-reported; app telemetry is not required.

Target over the next seven days: **five completed external trials and three specific feedback reports**. These are learning targets, not measured results. Downloads alone are not installations, unique people, or activation.

Voluntary feedback fields: distribution, desktop/session, package, app version, capture succeeded, OCR search succeeded, copy/drag succeeded, failing step, intended workflow, and whether importing existing captures would help. GitHub issues are public: exclude private screenshots, secrets, personal identifiers, and identifying logs.

## Actual demonstration brief

Use published v0.3.2 on Ubuntu/Debian x86_64 in a supported session. Confirm the downloaded package checksum first. Use a fresh test library or a library containing only approved synthetic examples; preserve the user's real library.

- 0–8 seconds: show harmless terminal text `permission denied` and capture its area.
- 8–20 seconds: let OCR finish and show the result; keep the wait honest rather than claiming a benchmark.
- 20–32 seconds: search `permission denied` among three different captures and open the matching PNG.
- 32–45 seconds: copy or drag the PNG into an app that accepts images; show the local library and no-account workflow.

Record actual successes and failures. Keep optional vision off so the demonstration proves the default OCR workflow. Add captions and a poster from the real recording, then replace the illustrative homepage panel with the recording once it passes. Do not advertise import, continuous screen memory, semantic search, notarization, or Windows installers.
